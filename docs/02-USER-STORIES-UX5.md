# ユーザーストーリー & UX5階層（実装前・戦略層から）

## ユーザーストーリー
| ユーザー | 欲しいこと・理由 | 受け入れ条件 |
|---|---|---|
| **本命**: テック早期採用者（25–40・新デバイス品評が趣味） | NOVAが何で・何ができ・いくらかを3分で把握し予約判断したい | FV3秒で製品カテゴリが分かる／機能は1スクロール1メッセージ／$299とPre-orderが常時1タップ圏 |
| **救う相手**: スマホ疲れの多忙な社会人 | 画面を見ない生活の具体像を知りたい | Everydayの4場面が自分の1日に重なる／専門用語なしのコピー／会話デモで「話しかけるだけ」を体感 |
| 副次: デザイナー・技術者（品評視点） | 技術の裏付けと作りの精度を確認したい | Technology5項目と分解ビュー／Specs数値／操作の滑らかさ |

## UX5階層（決定事項）
1. **戦略**: 差別化源泉=「画面を持たないAI」。だからサイト自体も“UIが消える”体験にする——
   カード・枠・線を極小化し、闇の中に文字とプロダクトだけが浮かぶ。情報量より情緒。目標はPre-order意欲。
2. **要件**: 9セクション＋会話デモ＋分解ビュー＋シェア/OGP。対象外=EC・実AI・多言語・ブログ。
3. **構造**: 単一ページ縦一本道（分岐ゼロ）。ナビはアンカーのみ。唯一のモーダル=Pre-order（架空である旨→閉じて復帰）。
   3Dは「1つのデバイスが全セクションを旅する」単一物語軸（セクション毎の独立ビジュアル案は棄却）。
4. **骨格**: 各画面の最大要素は1つ——Hero:ワードマーク／Reveal:見出し／Experience:会話パネル／
   Technology:分解3D／Everyday:シーン引用／Specs:数値／CTA:デバイス+価格。プライマリボタンは常に1個。
5. **表層**: 4色以内=黒#050507・白#f4f6f8・グレー#9aa3b2系・藍紫#7c8cff（発光専用）。赤緑対比なし。
   Space Grotesk+Inter。モーション基準=呼吸（300–700ms・easeOutQuart）。Bloomはデバイスの光輪限定。

## この5階層を通して変わった実装判断（**7個**）
1. 戦略「UIが消える」→ 当初構想のガラスカード多用を全廃。区切りは余白と文字階層のみ（例外は会話パネル1枚=「NOVAが持たない画面」の暗喩）
2. 戦略「画面を持たないAI」→ 会話デモをメッセンジャー風吹き出しから「波形オーブ+字幕型」のミニマル表現へ変更
3. 構造「一本道」→ Everydayの横スワイプカルーセル案を棄却、タブ+クロスフェードに（スクロールハイジャック回避）
4. 骨格「最大要素1つ」→ Heroのボタン2個案（Pre-order+Watch film)を棄却、ボタン0+スクロールキューのみ（Pre-orderはナビに常設）
   **【周3で改訂】** 2周の独立採点が共に「転換導線の欠落」と指摘（3秒理解・CTA導線が1点で停滞）。骨格判断を撤回し、
   Heroに主CTA`Pre-order · $299`＋ゴースト`See the specs`を設置（最大要素はワードマークのまま・ボタンは小さく従属）
5. 表層「発光は光輪限定」→ 見出しグラデ発光・ボタン常時グローを削除、Bloom対象をリングのみに限定
6. 骨格モバイル→ ピン留め区間を300vh→220vhに短縮・3Dの左右移動を無効化して中央固定（親指スクロール距離と画面はみ出し対策）
7. 表層・色覚配慮→ Everydayのシーン識別を「色相のみ」から「色相+テキストラベル+アイコン形状」の三重符号化へ
